# Agent file disposition

SDK-native review candidate for [#1536](https://github.com/lifeodyssey/animichi/issues/1536), under [#1356](https://github.com/lifeodyssey/animichi/issues/1356). **Review evidence is recorded on the story PR.** No runtime migration or successor card is complete.

The owner's latest direction permits major internal deletion/rewrite and rejects an adapter layer. This inventory supersedes the earlier 28-delete / 42-adapter / 45-keep candidate. Its former adapter retention promise is withdrawn. The [SDK-native design review](SDK-NATIVE-REWRITE-REVIEW.md) gives the actual call chain, public-source evidence and required corrections to the [accepted spec](../../specs/2026-09-09-agent-on-pi-harness-spec.md). The parent story owns those canonical amendments; this document does not create a second architecture story.

## Historical snapshot and decision rules

- Base: `fd73fbd532ef4d151a027ab8c93e9f2ea9304dab`. The tracked `workers/edge/src/agent/` tree contains **115 files**, 114 TypeScript files plus `city-names.json`, and **13,449 lines**. Each path is listed once; line counts are read from this Git object, not inferred from globbing or future target files.
- Revised decisions: **47 delete / 43 rewrite-domain / 25 retain-domain**. The additional eight companion rows are outside this denominator.
- **delete** removes the old file/interface/engine from the target. Its stated business obligations move to native SDK operations or ordinary domain code before cutover. It never deletes user data or applied migration history.
- **rewrite-domain** removes the named old wrapper. Each row states **Remove / Use / Keep**: old abstraction removed, concrete public dependency seam, and the remaining domain responsibility. It promises neither a renamed class nor a retained file boundary.
- **retain-domain** keeps ordinary domain rules/data or an explicitly isolated historical decoder. It does not freeze old imports, comments, types, internal JSON shapes or class architecture.
- Native assembly in `packages/agent` returns SDK objects. Edge owns authenticated HTTP/platform hosting; `packages/pi-session-neon` implements SDK Storage/SessionRepo directly. No TurnStore-to-pi conversion chain, ToolPolicy port, SelectionRecords port, generic Toolbox, or replacement Models interface.
